# Подход к решению

## Обработка признаков

В признаках решил удалить столбцы:

- `PassengerId`
- `Name`

Из признака `Cabin` сделал 3 новых признака:

- номер каюты;
- палуба;
- сторона корабля.

После этого исходный признак `Cabin` удалил.

---

## Baseline

В качестве baseline выбрал Logistic Regression.

Дальше попробовал убрать признаки через L1-регуляризацию, но результат стал незначительно лучше, а разброс результатов увеличился. Поэтому дальше отбор признаков через L1 не применял.

---

## Модели

Затем попробовал применять более сложные модели:

- Random Forest;
- CatBoost;
- Gradient Boosting.

Для моделей подбирал гиперпараметры через случайный поиск.

Лучше всего себя показал CatBoost.

---

## Ансамбли

На основе лучших моделей сделал взвешенный blending и stacking.

Улучшений они не показали, поэтому в качестве финальной модели оставил CatBoost с её лучшими параметрами.

---

# Идеи, вопросы и мысли, которые не успел или не смог реализовать

В целом, как я понял, нужно было выжимать больше информации из признаков `Name`, `PassengerId`, возраста и расходов.

## Name

Для имени можно было попробовать выделить семьи, но я подумал, что такие люди будут жить рядом или находиться в одной группе, поэтому это не понадобится. Возможно, это было ошибочным решением.

## PassengerId

Для `PassengerId` можно было создать признак групп, так как там указана принадлежность пассажиров к определённой группе и порядковый номер внутри неё.

## Age

Возраст можно было разбить на категории:

- ребёнок;
- подросток;
- взрослый;
- пожилой и т.д.

Хотя я не совсем понимаю, насколько это могло улучшить предсказания. Здесь я скорее пытаюсь логически объяснить ситуацию из датасета, но явной связи возраста с целевой переменной не вижу. Возможно, эта связь просто неочевидная или плохо объясняется логически.

## Расходы

Как я понял, расходы можно было объединить в один общий показатель и отдельно оценивать его влияние. Но здесь тоже не совсем понимаю, насколько это могло улучшить результат, ведь у нас уже есть все составляющие этой суммы.

---

Даже после этого пробовал загнать такие улучшения по признакам в нейронную сеть, но сильного улучшения не получил. При этом времени на полноценную проверку кода нейронной сети не было, поэтому возможно, что там были ошибки и модель работала не совсем корректно.

Не понимаю, насколько сильно в данном датасете влияет обработка признаков. У лучшего участника leaderboard результат около **0.96**, но я пока не понимаю, за счёт чего можно преодолеть даже порог в **0.82**.

Возможно, больший упор нужно делать на модели, а возможно, именно обработка признаков в данном датасете играет большую роль и исходные данные плохо подходят для обучения без дополнительной обработки.

Понимаю, что итоговый результат получается за счёт совокупности всех улучшений, но всё равно интересно, что именно даёт основной прирост.

Не совсем понятно, за счёт чего лучшие решения в leaderboard получили такую точность, так как все мои изменения улучшали результат максимум в пределах нескольких сотых accuracy.

---

## CatBoost

С CatBoost, скорее всего, я работал не совсем правильно.

Эта модель хорошо работает с категориальными признаками в исходном виде, а я подавал признаки уже после One-Hot Encoding. Возможно, из-за этого результат мог ухудшиться.

Не до конца понимаю, насколько сильно это влияет: ухудшается ли качество модели или это в основном влияет только на удобство и количество используемой памяти.

---

## Работа с категориальными признаками

Есть проблемы с пониманием того, как правильно оценивать категориальные признаки.

С числовыми признаками понятно, какие методы можно применять:

- корреляции;
- PCA;
- различные графики.

А вот с категориальными признаками не совсем понятно, как проводить такой же глубокий анализ.

Особенно это стало заметно, когда в начале я взял датасет **Porto Seguro’s Safe Driver Prediction**. Там все признаки были безымянные, и единственный способ их оценивать — через EDA, графики и таблицы.

---

В целом хотелось бы посмотреть на работу с результатом значительно выше моего: либо код, либо описание подхода к датасету.

Пока я не совсем понимаю, за счёт чего можно значительно улучшить результат без использования нейронных сетей или каких-то очень продвинутых моделей.

В leaderboard у лучших работ нет открытого кода, поэтому сложно понять, какие именно подходы дали такой большой прирост.

# Инструкция по запуску проекта

## 1. Клонирование репозитория

Сначала необходимо скачать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейти в папку проекта:

```bash
cd <название-папки>
```

---

## 2. Создание виртуального окружения

Создать виртуальное окружение Python:

```bash
python -m venv venv
```

Активировать виртуальное окружение.

### Windows:

```bash
venv\\Scripts\\activate
```

### Linux / macOS:

```bash
source venv/bin/activate
```

---

## 3. Установка зависимостей

Установить необходимые библиотеки:

```bash
pip install -r requirements.txt
```

---

## 4. Подготовка данных

Для запуска ноутбука необходимо скачать данные соревнования Spaceship Titanic:

https://www.kaggle.com/competitions/spaceship-titanic/data

Необходимые файлы:

- `train.csv`
- `test.csv`

нужно разместить в папке c `spaceship_titanic.ipynb`.

---

## 5. Запуск Jupyter Notebook

После установки зависимостей запустить:

```bash
jupyter notebook
```

Открыть файл:

```
spaceship_titanic.ipynb
```

и выполнить все ячейки последовательно.

---

## 6. Получение результата

После выполнения ноутбука будет создан файл:

```
submission.csv
```
