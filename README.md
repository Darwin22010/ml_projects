# League of Legends Match Winner Prediction

Исходный датасет:

https://www.kaggle.com/datasets/datasnaek/league-of-legends/data

Подробное описание работы, проведённых экспериментов и результатов находится в PDF-отчёте.

# Инструкция по запуску проекта

## 1. Клонирование репозитория

Сначала необходимо скачать репозиторий:

```bash
git clone https://github.com/Darwin22010/ml_projects/tree/league_of_legends_games
```

Перейти в папку проекта:

```bash
cd <название-папки>
```

---

## 2. Создание виртуального окружения

Создать виртуальное окружение Python:

```bash
python -m venv venv
```

Активировать виртуальное окружение.

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Установка зависимостей

Установить необходимые библиотеки:

```bash
python -m pip install -r requirements.txt
```

---

## 4. Данные

В репозитории уже находятся подготовленные выборки:

- `train_games.csv`
- `test_games.csv`

Их необходимо оставить в одной папке с основным Jupyter Notebook.

Дополнительно в репозитории находится код, который использовался для первоначального разделения исходного датасета на train и test.

Для обычного запуска проекта выполнять его не требуется, так как готовые `train_games.csv` и `test_games.csv` уже приложены.

Скрипт `lol_train_test_split.py` оставлен для воспроизводимости первоначального разбиения данных.

---

## 5. Запуск Jupyter Notebook

После установки зависимостей запустить:

```bash
jupyter notebook
```

Открыть основной файл проекта:

```text
lol_dataset.ipynb
```

и выполнить все ячейки последовательно сверху вниз.

Часть экспериментов, особенно подбор гиперпараметров и обучение MLP с кросс-валидацией, может выполняться продолжительное время.

При наличии CUDA-совместимой видеокарты обучение MLP будет выполняться на GPU. При отсутствии CUDA будет использоваться CPU.

---
